# 운동 메이트 (P2P) — v1 스펙 (2026-08-21 사장님 확정)

고객끼리 운동 메이트를 구하는 별도 섹션. 만날 장소는 매칭된 채팅방에서 직접 협의한다.
**무료로 시작** — 추후 매칭 성사·채팅 개설 등에 토큰 소비를 붙이는 것이 확정 방향이므로,
과금 지점에 자리만 마련해둔다(현재 소비량 0).

## 확정 사항 (사장님)

- 남남/남녀 조합 선택 가능 (동성만 / 성별 무관)
- 장소는 시스템이 정하지 않는다 — 매칭 채팅에서 자유 협의
- 비용 없음(v1). 추후 토큰 소비 방식(매칭·채팅 개설 등)으로 전환 예정

## 법적 전제 (리서치 조사 — 협상 불가)

P2P도 "불특정 이용자 간 만남 주선"으로 파트너 데이트와 **동일 규제**(청소년유해매체물
지정 기준)를 받는다. 성별 조합과 무관하다. 따라서:

1. 성인인증 게이트 — 기존 전역 게이트 그대로 적용 (신규 작업 없음)
2. **대화 저장 의무** — 운동 메이트 채팅도 삭제 불가 로그 (update/delete 정책 없음 패턴)
3. 신고 기능 — 기존 신고 체계에 메이트 채팅 연결
4. 조건만남 금칙어 + 연락처 유도 감지 — 기존 트리거와 동일 배선
5. **정식 오픈 전 법무 확인 1회 게이트** — 스포츠 매칭 유형의 유해매체물 해당 여부 +
   부상 책임 면책 약관 (플랫폼은 주선만 하고 활동을 주최하지 않는다는 조항)

## v1 도메인 설계 방향

기존 채팅·예약 인프라는 booking(고객↔파트너) 전용이라 재사용 불가 (감사 확인).
신규 feature 도메인 `features/sportsMate/`로 만든다.

- **모집글** `sports_mate_posts`: 작성자, 종목(배드민턴·풋살·볼링 — COURSE_CATEGORIES의
  운동 항목과 라벨 동기화), 지역(권역, constants/regions.ts), 희망 날짜·시간대,
  성별 조합(same_gender | any), 한마디(금칙어 검사), 상태(open | matched | closed)
- **신청/수락** `sports_mate_requests`: 신청자 → 작성자 수락 → 매칭 성사
- **매칭 채팅** `sports_mate_messages`: 예약 채팅과 동일한 보안 패턴
  (당사자만 select/insert, update/delete 정책 없음 = 로그 보관, flagged 트리거 배선)
- 노출 최소화: 닉네임만. 위치 프라이버시 헌장 준수(권역 단위만, 좌표·주소 금지)
- 과금 자리: 매칭 성사 시점에 `spend_tokens` 호출 지점만 마련, v1 비용 0

## 진행 순서

1. 담당1(위치 필터)·담당2(연락처 감지) 완료 후 최우선 배정
2. 1단계: 스키마 + 모집글 CRUD + 탐색 탭 → 2단계: 신청/수락 + 매칭 채팅 →
   3단계: 신고·감지 배선 검증(임퍼스네이션 리허설) 후 공개
3. 법무 확인 게이트는 공개 전 사장님 결정 리스트에 유지
