# 렌탈 데이트 업계 사건·리스크 사례집 (2026-08-21, 리서치 조사)

법무 검토·인수인계·안전장치 우선순위 판단의 근거 자료. 출처는 리서치 담당 웹 조사 —
"미확인"은 검색으로 못 찾았다는 뜻이지 "없다"는 뜻이 아니다.

## 일본 실사례

- **2018 오사카**: "렌탈카노조" 구인공고로 여성을 모집한 뒤 실제로는 성매매업소에
  알선한 사기 구조 적발 — 알선업체 대표 등 4명 직업안정법 위반 체포.
  정당한 서비스 간판이 성매매 모집의 **위장막(미끼 채용공고)**으로 악용된 사례.
- **2023 도쿄·후쿠오카**: 매칭앱으로 남성 7명·여성 2명을 성매매 목적으로 연결한
  알선업자 4명 체포. CLAUDE.md 법적 제약 3번이 경계하는 시나리오 그대로.
- 미확인: 캐스트 스토킹 구체 사례, 국민생활센터 소비자 트러블 통계.

## 국내 지형

- 실운영 서비스 다수: 위드유(with-u.kr), 쏠메이트(2015~), 쿠와, 시라노에이전시 등.
  규칙은 일본과 유사(밀실·스킨십 금지, 시도만 해도 즉시중단+환불없음, 실비 신청자 부담).
  이용자 규모는 어느 곳도 비공개 (일본 렌카노 "누적 6만" 자체 공개와 대조).
- **특정 업체 형사처벌 사례는 이번 조사로 미확인.** 단 업계 전반 평가(나무위키
  "연인 대행 업체")는 "규칙은 있으나 현장 괴리 + 적발돼도 당사자 합의로 회피 →
  단속 사실상 불가능" — 알선 적극 가담보다 **방치·묵인형 실패**가 지배적 그림.
- ⚠️ 처벌 사례 부재 ≠ 안전. "아직 단속망에 안 걸렸을 뿐"일 가능성으로 읽고
  더 조심할 신호로 취급한다.

## 우리 장치와의 갭 분석 (조사 결론)

국내 업체들의 명시 규칙은 우리와 거의 같다. 차이는 **"규칙을 어겼을 때 뭐가 남는가"**:
공개 확인 범위에서 국내 업체들은 채팅 저장·신고·감지 같은 기술 장치를 명시하지 않는
반면, 우리는 채팅 전량 저장(삭제 불가) + 조건만남 키워드 감지 + 연락처 유출 감지 +
신고 체계를 갖췄다. **"위반 시 증거가 남고 추적 가능한가"가 업계 실패 지점과 우리의
차별점이자, 안전장치 투자를 계속해야 하는 이유다.**
