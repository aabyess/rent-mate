# 디자인 시안 원본

웹에서 보는 캔버스: https://claude.ai/code/artifact/756bf44c-0ff0-4662-9f00-c83ae57ddf8f

이 폴더는 위 캔버스에 올라간 시안의 원본 소스(아트보드별 `.dc.html` + 레이아웃 `canvas.json`)의 보존용 사본이다.
앱 코드가 아니며 빌드에 포함되지 않는다. 디자인 기준 문서는 `docs/design-guide.md`.

| 파일                                                | 내용                                        |
| --------------------------------------------------- | ------------------------------------------- |
| `Main` `PartnerDetail` `Booking` `Chat` `MyPage`    | 현재 시안 (확정 팔레트: 코랄 + zinc)        |
| `Apple*` 5종                                        | 애플화 버전 (design-guide ⑥장 원칙 적용)    |
| `HomeBlue` `HomeTeal` `HomeRose`                    | 미채택 컬러 대안 B·C·D (탐색 기록)          |
| `canvas.json`                                       | 캔버스 배치·페이지·메모                     |
